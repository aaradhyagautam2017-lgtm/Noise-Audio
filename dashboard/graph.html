Hover a component to spotlight everything it is wired to; drag a node to reposition it; scroll or use the controls to zoom; click a node to open its dashboard page. The identical data is queryable by the agent at graph/graph.json (and embedded in this page), with every node exposing id, node_id and figma_fingerprint.
