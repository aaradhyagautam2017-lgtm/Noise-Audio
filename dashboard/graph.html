Component graph

The canonical wiring of the library, generated from registry.yaml in one pass — it renders only nodes and edges that exist there, at fixed, deterministic positions (registry order, tiered by type). Hover a component to spotlight everything it is wired to; click it to open its dashboard page. The identical data is queryable by the agent at graph/graph.json (and embedded in this page), with every node exposing id, node_id and figma_fingerprint.

Legend atom molecule organism complex-organism solid = is built from (part → whole) dashed = behavioral relationship red = dangling reference (32, registry-flagged) size = usage count

Dangling references are drawn to ghost markers on the right — components the registry says exist outside the ingested library page. They are shown as broken, never repaired (details: INGESTION_REPORT.md §5).
