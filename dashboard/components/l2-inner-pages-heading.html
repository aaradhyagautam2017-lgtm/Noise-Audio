Usage

Used as the primary heading for inner pages that exist one level deeper than surface-level pages.

Design intent

Provide clear navigation hierarchy by identifying the primary destination within an inner-page experience.

Anti-patterns

  • not-on-surface-level Do not use on surface-level pages.
  • not-as-section-heading Do not use as a section heading.
  • not-inside-containers Do not use inside cards, sheets, or modals.
  • not-for-l1-hierarchy Do not use for L1 page hierarchy.
  • not-for-content-grouping Do not use for content grouping.

Rules

hierarchy
  • Must always represent L2 page hierarchy.
  • Must only appear on inner pages.
  • Must appear below L1 content hierarchy.
  • Sits flush directly under the L1 inner page navigation, with no padding or spacing between them.
content
  • Should communicate the page destination or purpose.
  • Prefer concise and scannable wording.
  • Max 2 line content is supported.
layout
  • Height is content driven.
  • Minimum height is 56px.
  • When content occupies a single line, component height remains 56px.
  • When content wraps, height expands based on content.
scroll_behavior
  • When page content overflows the first fold and the user scrolls up, this heading collapses and its text promotes into the L1 inner page navigation's centered heading slot.
  • Promotion applies only when the active L1 variant is a base variant (clean-only-chevron, one-icon, two-icon); it does not occur with ai-token-banner or items-selected.
  • The transition is a smooth animation, and reverses on scroll-down.
