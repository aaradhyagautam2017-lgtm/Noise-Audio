Usage

This is the master card used in the majority of table cell use cases. Can be used as a standalone card or as a row within a grouped list.

Design intent

Provide a flexible row pattern that supports both standalone surfaces and grouped lists while maintaining consistent content hierarchy and interaction patterns.

Anti-patterns

  • no-dual-corner-radius Do not apply both row-level and container-level corner radius simultaneously.
  • no-standalone-when-grouped Do not use standalone cards when multiple related items should be grouped.
  • grouped-list-requires-separators Do not use grouped-list mode without enabling separator lines between rows.
  • single-primary-actionable-per-row Do not place more than one primary actionable in a row.
  • notification-chin-standalone-only Notification chin can only be used with a standalone card.
  • no-separator-with-standalone-or-chin Do not add a separator line to a standalone card or a card with a notification chin.
  • no-stroke Do not add a stroke to the component regardless of it being a standalone component or a table cell component.

Rules

  • single-primary-actionable Only one primary actionable per row.
  • actionables-right-aligned Actionables always remain right aligned.
  • actionable-replacement-no-layout-shift Replacing an actionable must not affect content layout.
  • actionables-inherit-vertical-alignment Actionables inherit the component's vertical alignment.
  • no-checkbox-in-this-component Never add a checkbox in this component even though it is in the actionables.
  • separator-inset The separator line between rows is inset, not full-width. It begins at the start of the text/content block (aligned after the leading icon) and runs to the trailing edge. It must never extend under the leading icon. Applies only in grouped-list mode.
