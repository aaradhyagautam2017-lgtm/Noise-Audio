Metadata rendered from the stored authored YAML

Usage

Used at the L1 inner pages layer to communicate page context and provide access to navigation and page-specific actions.

Design intent

Provide users with clear orientation within an inner-page flow while maintaining access to navigation and contextual actions.

Anti-patterns

  • not-on-surface-level Do not use on surface-level pages.
  • not-inside-containers Do not use inside cards or content containers.
  • not-more-than-once Do not use more than once on a page.
  • not-as-section-header Do not use as a section header.
  • not-for-content-grouping Do not use for content grouping.
  • not-replace-l2-headings Do not replace L2 page headings.

Rules

hierarchy
  • Must represent L1 page hierarchy.
  • Must always appear below the status bar.
  • Must always appear above page content.
variant_selection
  • Choose the simplest variant capable of supporting required actions.
  • Do not add trailing actions unless a clear user need exists.
  • Items Selected should only appear during active selection states.
layout
  • Must span the page width.
  • Title remains the primary focal element.
  • Navigation actions should remain visually secondary to the page title.
scroll_behavior
  • On scroll (when page content overflows the first fold), receives the promoted heading from the L2/Inner pages Heading into its centered slot. Applies only to base variants (clean-only-chevron, one-icon, two-icon); ai-token-banner and items-selected never receive a heading.
  • On scroll, the L1 nav container and the status bar container gain a fill of token/background/canvas (both are transparent at rest) so scrolling content does not bleed through.
  • On scroll, a subtle drop shadow appears on the L1 nav. The shadow is directional: cast downward only, from the bottom edge of the L1 nav, so it reads as content passing underneath. It must never extend upward onto the status bar.
  • The transition is a smooth animation, and reverses on scroll-down.
shadow_exception
  • This is the only component in the system that uses a drop shadow. Shadows must not be introduced anywhere else in the app.
