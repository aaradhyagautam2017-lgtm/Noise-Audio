type_note: An organism containing an organism or atom (the content variant).

Purpose

The full modal surface — a grey dimming overlay with content anchored to the bottom — used to present an unavoidable action the user must take.

Usage

Used when the user must complete an action they cannot skip. Follows the same container behavior as the Action sheet, except it is not freely dismissible.

Design intent

Force an unavoidable decision at a break in the flow, presenting the required action on a surface the user cannot casually dismiss.

Anti-patterns

  • not-for-optional-actions Do not use for optional, skippable actions; use the Action sheet instead.
  • no-internal-scroll Do not allow the content to scroll internally; the sheet grows to fit its content.
  • never-cover-status-bar Do not obscure or recolor the status bar with the overlay; the status bar stays on top in its dedicated contrasting token.
  • no-extra-dismissal Do not add a cross or any dismissal affordance beyond the ones each variant explicitly permits.

Rules

placement
  • The sheet is anchored (stuck) to the bottom of the screen and grows upward to fit its content.
scroll
  • The content must never scroll; height is content-driven and expands upward instead.
motion
  • Enters from the bottom (slides up) and exits to the bottom (slides down), with the overlay fading accordingly. Smooth animation.
status_bar
  • Stays on top of the overlay in a contrasting color drawn from its dedicated token; the overlay never covers or recolors it.
dismissal
  • Dismissible only via the actions (the Modal card's CTAs). No overlay-tap, no swipe-down, no cross.
    variant

  • Dismissible only by tapping outside the placeholder, or by choosing one of the options inside the native pop-up. These are the only two ways. This follows the device's own native pop-up conventions, not ours.

  • Use the Modal sheet when the action is unavoidable and cannot be skipped. For optional, skippable actions, use the Action sheet. (Mirror of the shared action-vs-modal rule.)
