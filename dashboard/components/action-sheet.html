type_note: An organism containing an organism (the Action card).

Purpose

The full action-sheet surface — a grey dimming overlay with an Action card anchored to the bottom — used to present an optional, skippable action.

Usage

Used when the user should be offered an action they can take or skip (e.g. upload a profile image, set a birthday). The Action card inside carries the content; this component owns the overlay, placement, and dismissal.

Design intent

Give optional actions a lightweight, dismissible surface that interrupts the flow only as much as needed and lets the user return to the page freely.

Anti-patterns

  • not-for-unavoidable-actions Do not use for unavoidable actions the user must complete; use the Modal sheet instead.
  • no-internal-scroll Do not allow the Action card inside to scroll; the sheet grows to fit its content rather than scrolling internally.
  • never-cover-status-bar Do not obscure or recolor the status bar with the overlay; the status bar stays on top in its dedicated contrasting token.

Rules

placement
  • The sheet is anchored (stuck) to the bottom of the screen and grows upward to fit the Action card's content.
scroll
  • The Action card must never scroll; the sheet's height is content-driven and expands upward instead.
dismissal
  • Optional action — all dismissal paths permitted: tapping the grey overlay, swiping the sheet down, or the Action card's cross (X). Any of these dismisses it. This permissiveness is the defining contrast with the Modal sheet, which allows none.
motion
  • Enters from the bottom (slides up) and exits to the bottom (slides down), with the overlay fading accordingly. Smooth animation.
status_bar
  • The status bar stays on top of the overlay in a contrasting color drawn from its dedicated token; the overlay never covers or recolors it.
usage_boundary
  • Use the Action sheet when the action is optional and skippable. For unavoidable actions, use the Modal sheet. (Mirror of the shared action-vs-modal rule.)
