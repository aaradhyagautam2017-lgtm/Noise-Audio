Purpose

The white content block of a modal — presents an unavoidable action the user must take, with a fixed set of structures.

Usage

Used as the content block inside a Modal sheet (Modal card + grey overlay). The agent selects the variant, then sets the allowed toggles.

Design intent

Force a clear, unavoidable decision at a break in the flow, presenting the required action (and any supporting detail) in a consistent, non-dismissible surface.

Anti-patterns

  • not-standalone Do not use the Modal card on its own; it only exists inside a Modal sheet (paired with the grey overlay).
  • no-dismissal-affordance Do not add any dismissal affordance (cross, chevron, tap-outside-to- close). A modal must be acted upon and cannot be skipped.
  • no-invented-variants Do not invent new variant structures; the set is locked.
  • download-list-scope Do not use the download-list variant for anything other than showing current downloads.

Rules

dismissal
  • No dismissal affordance of any kind (no cross, no chevron, no tap-outside-to-dismiss). The user must take an action.
structure
  • The heading is mandatory in the default modal.
  • The variant structures are locked; the download-list variant's structure is fixed and non-toggleable.
content_placement
  • Content vs Content box (strict): regular informational text — informing or telling the user something — goes in the content (subheading). The content box is a special container reserved for special/structured content: lists, steps, directions, feature lists, and the like. Informational prose -> content; structured/special content -> content box.
composition_workflow
  • Agent order: choose the variant, then (for the default modal) set the content toggle, the content-box toggle and its inner small-heading toggle, and which of the three CTAs are present.
usage_boundary
  • Use the Modal card (within a Modal sheet) when the action is unavoidable and cannot be skipped. For optional, skippable actions, use the Action card / Action sheet instead. (Mirror of the shared action-vs-modal rule.)
