Metadata (rendered from the stored authored YAML)

Purpose

A placeholder standing in for an image or asset, in a fixed set of sizes, plus mock stand-ins for a device-native pop-up and a transcribing/loading state.

Usage

Used wherever a design needs a placeholder for an image, avatar, device mock, native pop-up, or loading state. Because these are raw primitives, the specific use case for any variant is defined by the organism or molecule that uses it — not here.

Design intent

Provide a consistent, fixed library of placeholders so any design can represent images, assets, device mocks, native pop-ups, and loading states uniformly, without bespoke placeholder sizes.

Anti-patterns

  • no-resize Do not change the placeholder sizes; the size set is fixed and locked.
  • native-popup-is-mock-only Do not use the device-native-pop-up variant to build real OS pop-ups; it is only a mock stand-in (the library does not reproduce native pop-ups).
